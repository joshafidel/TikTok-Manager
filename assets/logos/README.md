# Channel logos

Profile pictures for the three TikTok accounts. TikTok crops avatars to a
circle and shows them around 40px in feed, so each mark is built to survive
at that size: one idea, high contrast, no fine detail, and no text.

| File | Channel | Mark |
|---|---|---|
| `ai-with-receipts.png` | AI, with receipts | A receipt with a torn edge and a check — proof, not hype |
| `reactions.png` | Reactions | Bug-eyed recoil with a grimace |
| `tally.png` | Tally | Four strokes and a cross — the name is the mark |

Each is 1000×1000 PNG, well above TikTok's 200×200 minimum. Upload the PNG
directly as the profile photo.

`proof.png` shows all three circle-cropped at 180 / 110 / 64 / 40px.

## Editing

The PNGs are rendered from the SVGs, which are generated by `build.js`.
Change a colour or shape there and re-run:

```bash
node build.js        # regenerate the SVGs
```

Then re-render to PNG with any SVG tool. The grounds are deliberately darker
than the channel accent colours used in the app, so the marks stay legible
on TikTok's dark UI.
